## 1. 게임 정의와 콘셉트

PixelTown은 2000년대 싸이월드 미니홈피의 "미니룸"을 걸어 다니는 느낌의 작은 도트 마을이다. 친구의 미니홈피 프레임 안에서 아바타가 광장·정원·오락실을 산책하고, 채팅 말풍선으로 인사하고, 30초 별 모으기를 함께 한다. 원 서비스의 코드·이미지·통신망은 쓰지 않는다. 모든 그래픽은 자체 절차 코드로 그린 도트이며 폰트는 OFL 라이선스 Galmuri11을 로컬 번들한다.

## 2. 목표와 범위

목표는 "싸이월드 미니룸을 걸어 다니는 도트 마을"을 실제 플레이 가능한 수준으로 만드는 것이다. 로그인 → 마을 입장 → 산책·충돌·깊이 → 채팅 → 별 모으기 → 점수·보상 조회 흐름을 로컬 서버와 연결한다. 두 계정 동기화와 20명 로컬 smoke를 유지한다.

이번 범위: 미니홈피 프레임 UI, 3개 장소 신규 맵, 공용 맵·충돌 모듈, 3계층 깊이 렌더링, 2등신 아바타, 키보드·방향패드·클릭/탭 이동, 장소 간 출입구 이동, 기존 채팅·별 모으기·결과·보상 계약.
후속 범위: 아바타 꾸미기 저장, 상점·결제, 친구·쪽지·방명록, 개인 미니룸 꾸미기, 100명 운영, 실기기 키보드 보증, 운영 배포. 회원가입 UI는 계속 제외한다.

## 4. 핵심 루프와 게임 경험

`로그인 → 광장 입장 → 산책(나무 뒤로 숨고 앞으로 나옴) → 채팅·인사 → 별 모으기 시작 → 별 가까이 이동 → 서버 점수 → 순위 → 수첩에서 기록·별 보상 → 다른 장소로 이동`.

### 4.1 맵 기획 (40×26 타일, 타일 16 도트, 월드 640×416)

세 장소는 바닥 재질, 구획, 동선, 소품, 목적이 모두 다르다. 출입구 매트를 밟으면 연결된 장소의 맞은편 입구로 이동한다. 우측 탭으로도 바로 이동할 수 있다.

**타운 광장 `lobby` — 만남의 장소.** 잔디 마을 한가운데 원형 석재 광장과 분수가 있다. 네 방향 모래길이 광장에서 뻗는다. 북쪽 길은 게시판 앞을 지나 두 건물(분홍 지붕 "미니홈피 하우스", 파란 지붕 "선물가게") 문 앞에 닿는다. 동쪽 길 끝 출입구는 정원, 서쪽 길 끝 출입구는 오락실로 이어진다. 남쪽 길에는 마을 입구 아치(foreground)가 걸려 있고 그 아래가 시작 지점이다. 광장 둘레에 벤치·가로등·화분이 있다. 가장자리에는 나무숲과 울타리를 둔다. 의도된 동선: 아치 아래 시작 → 분수 광장 → 게시판 → 건물 → 좌우 출입구.

**비밀 정원 `garden` — 산책과 대화.** 짙은 잔디와 디딤돌 길로 이루어진다. 서쪽 출입구(광장행)에서 덩굴 퍼걸러(foreground) 아래를 지나 연못으로 간다. 연못은 물 타일이라 들어갈 수 없다. 나무다리로만 건넌다. 다리 건너 북동쪽에 작은 온실이 있다. 남쪽에는 생울타리로 나눈 꽃밭 구획과 벤치 쉼터가 있다. 나무가 많아 나무 뒤로 숨는 깊이 표현이 가장 잘 드러나는 장소다. 의도된 동선: 입구 → 퍼걸러 → 연못 다리 → 온실 → 꽃밭 고리길 → 입구.

**스타 오락실 `arcade` — 별 모으기의 본거지.** 실내 맵이다. 위쪽은 네온 간판과 창문이 있는 벽이고 벽은 통과할 수 없다. 바닥은 보라·분홍 체크 타일이다. 북쪽 벽을 따라 오락기가 줄지어 있다. 가운데 등을 맞댄 오락기 섬이 있어 그 뒤로 지나가면 가려진다. 동쪽에는 인형뽑기 2대와 경품 카운터가 있다. 기둥 2개와 화분·소파가 있다. 남쪽 문 매트가 광장 서쪽 입구로 이어진다. 가운데 별 무대 러그가 미니게임 분위기를 만든다.

### 4.2 깊이와 충돌 규칙 (플레이어 체감 기준)

- 캐릭터·소품의 위치는 발밑(바닥 접점) 좌표다. 화면에서 발이 더 아래(남쪽)에 있는 것이 앞에 그려진다.
- 나무: 줄기 밑동만 막힌다. 캐릭터가 수관 아래(나무 북쪽)를 지나가면 수관에 가려진다. 나무 남쪽에 서면 나무 앞에 보인다.
- 건물: 벽의 바닥면만 막힌다. 지붕 그림 위쪽(건물 북쪽 뒤편 잔디)은 걸을 수 있고, 그곳에 서면 지붕에 가려진다.
- 아치·퍼걸러 상단은 항상 캐릭터 위에 그린다(foreground). 기둥만 막힌다.
- 물·벽·울타리·생울타리·꽃밭 타일은 통과할 수 없다. 길·광장·다리·바닥·러그·출입구 매트는 걸을 수 있다.
- 이동은 축별로 미끄러진다. 모서리에 걸리면 이동 방향으로 몇 도트 비켜 주어 끼임을 막는다.
- 시작·재입장·출입구 도착 지점은 항상 비어 있는 바닥이다.

### 4.3 별 모으기 규칙

- 방마다 한 라운드를 공유한다. 기본 30초, 시작 시 별 5개, 방별 미회수 상한 12개.
- 1500ms마다 미회수가 12개 미만이면 1개 생성한다. 누락분을 한 번에 몰아서 만들지 않는다. 별 0개여도 조기 종료하지 않는다.
- 별은 시작 지점에서 걸어서 갈 수 있고 나무 수관·지붕에 가리지 않은 바닥에만 생긴다.
- 서버가 플레이어 발밑과 별 사이 거리 16도트(1타일) 이하인지 확인한다. 별 1개 = 1점. 먼저 승인된 사용자만 얻는다.
- 종료 시 상위 3명 순위(동점 같은 순위), 개인 별 보상 = 점수. 0점도 원장을 남긴다. `(match_id,user)`당 한 번만 확정한다.
- 진행 중 이탈자의 점수는 결과에 남는다. 방이 비면 라운드를 종료한다.

### 4.4 실패 경험

로그인 실패 이유 표시와 재입력. 연결 끊김 시 상태·재연결 버튼, 멀티 입력 비활성. 방 이동 시 채팅·위치·말풍선을 새 방 것으로 교체. 같은 사용자의 같은 방 중복 접속 거절. 저장 지연 시 "기록 저장 중/재시도 중" 표시. 혼자 둘러보기는 연습 모드로 표시하고 서버 기록·보상으로 인정하지 않는다.

| FR-009 장소별 맵 | 세 장소가 다른 타일맵·구획·동선·소품·목적, 출입구 연결 | 모든 걷는 영역이 시작점과 연결, 고립 구역 없음 | AC-015 |
| FR-010 깊이 렌더링 | ground / 정렬 소품·아바타·별 / foreground 3계층, 발밑 y 정렬, 이름표 최상단 | 소품 뒤 캐릭터 가림, 앞 캐릭터 노출 | AC-014 |

FR-004 상세: 배경 alpha만 20–95%로 바꾼다. 글자·버튼은 불투명하다. 슬라이더는 키보드로 조작한다. 설정은 localStorage에 저장·복원한다. 접힌 동안 받은 다른 사용자 메시지 수만 미읽음 배지에 누적하고 펼치면 해제한다. 최근 메시지는 보낸 아바타 머리 위 말풍선으로 4초 표시한다.

FR-003 상세: 클릭/탭한 지점까지 공용 걷기 격자로 경로를 찾아 방향 입력으로 따라간다. 서버는 여전히 방향 입력만 받는다. 키보드·방향패드 입력은 경로 이동을 취소한다. 걸을 수 없는 곳을 누르면 가장 가까운 걷는 칸으로 간다.

## 7. 공통 비즈니스 규칙

| ID | 규칙 |
|---|---|
| BR-001 | 사용자 ID는 PB authRefresh로 확정한다. 클라이언트의 ID·이름·색·점수 주장을 신뢰하지 않는다. |
| BR-002 | 장소는 lobby/garden/arcade만 허용한다. presence·채팅·게임은 방 단위다. 같은 사용자의 같은 방 중복 입장 금지. 입장 위치는 서버가 장소별 고정 입구 목록에서 고른다. |
| BR-003 | 이동·경계·충돌·별 거리·시간·점수는 서버 권한이다. 충돌 정의는 프런트·서버가 같은 공용 모듈을 쓴다. 대각 이동이 빠르지 않다. |
| BR-004 | 기본 30초·초기 별 5·상한 12·1500ms마다 상한 미만이면 1개·별 1개 1점·16도트 이내 수집. 별 0개 조기 종료 없음. |
| BR-005 | 결과·보상은 `(match_id,user)`당 한 번. 보상 `star` 수량 = 점수. |
| BR-006 | 결과·보상은 PB 트랜잭션으로 함께 저장. 영구 outbox 재시도와 재전달 멱등. |
| BR-007 | 사용자는 자신의 프로필·결과·인벤토리만 조회. 쓰기는 게임 서버 권한. |
| BR-008 | 채팅 배경만 20–95% alpha, 글자·조작 불투명, 설정 로컬 복원, 접힘 중 미읽음만 배지. |
| BR-009 | 연습 모드는 서버 기록·보상 없음. 서버·20명 검증 증거로 쓰지 않는다. |

| BR-012 | 소품은 visual bounds(그림)와 footprint(바닥 충돌)를 따로 가진다. footprint는 그림보다 작고 바닥 접점에 있다. 지붕·수관 그림 전체를 막지 않는다. |
| BR-013 | 렌더링은 정수배 확대만 쓴다. 픽셀 보간(smoothing)을 끈다. 도트 소품·아바타에는 1도트 짙은 외곽선을 둔다. |
