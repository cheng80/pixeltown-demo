### 배포 기반 우선 개발 (2026-10-08)

사용자 요구: 현재 환경을 유지하며 활동 중 체감 중단 없는 게임 로직 배포를 검증한다. Supabase·Vercel 이전, PocketBase 자체 업데이트·Mac mini 재부팅의 무중단화는 범위에 넣지 않는다. 실제 접속 불가 시 백엔드와 독립된 안내 페이지는 필요하다. 정상 배포 중에는 재접속 화면·입력 차단을 허용하지 않는다.

2026-10-09 추가: 외부 접속 경로의 일시적 끊김은 같은 게스트·방·세션으로 자동 복구한다. 복구 중에는 광장을 유지하고 작은 연결 확인 문구를 표시한다. 확인받지 못한 이동 예측은 연결 상태와 관계없이 최대3초 분량(기본60걸음)이며, 한도에 닿으면 위치를 고정하고 미확인 입력을 보존한 채 같은 세션을 복구한다. 끊기기 전과 복구 중 입력은 같은 한도를 공유한다. 서버가 확인한 상태로 복구하지 못하면 최대 12초·10회 시도 안에서 실패 안내와 수동 입장 버튼으로 전환한다. 새 계정 발급이나 점수 초기화를 복구로 취급하지 않는다. 접속 서버 자체가 재시작해 방이 사라진 경우에는 수동 재입장이 필요하다.

모든 별 소비·사용자 상태 변경을 먼저 조사하고, 기능을 최소화해 시스템을 구축한 뒤 기능을 순서대로 붙인다. [기능 조사](reviews/2026-10-08-game-state-audit.md)와 [PLAN-007](plans/PLAN-007.md)에 단일 메인 로비·이동·별 획득/정산을 남기는 최소 범위를 정했다. 새 `minimal/` 프런트와 전용 Colyseus·PocketBase를 기본 로컬 실행 대상으로 구축한다. 기존 게임은 별도 실행 경로로 유지하고, 기존 계정·보유품·별 원장·프로필·가구 배치를 새 DB로 옮기거나 지우지 않는다. 최소 게임은 별도 게스트 계정과 브라우저 저장소를 사용한다. 아래 전체 기능 명세는 기존 게임과 향후 재도입 기준으로 유지한다. 활동 중 worker 교체는 별도 로컬 환경에서 구현·검증했으며, 기존 실행 서버의 최초 구조 도입과 운영 전환은 별도 단계다. 실행 계약은 [최소 게임 안내](../minimal/README.md), 구조는 [배포 도식](diagrams/zero-downtime.html)을 참조한다.

## 1. 게임 정의와 콘셉트

PixelTown은 2000년대 싸이월드 미니홈피의 "미니룸"을 걸어 다니는 느낌의 작은 도트 마을이다. 친구의 미니홈피 프레임 안에서 아바타가 광장·정원·오락실을 산책하고, 채팅 말풍선으로 인사하고, 마을 곳곳에 생기는 별을 줍는다. 모은 별로 모자·옷·펫·가구를 사서 꾸미고 내 미니룸에 가구를 놓는다. 원 서비스의 코드·이미지·통신망은 쓰지 않는다. 모든 그래픽은 자체 절차 코드로 그린 도트이며 폰트는 OFL 라이선스 Galmuri11을 로컬 번들한다.

## 2. 목표와 범위

목표는 "싸이월드 미니룸을 걸어 다니는 도트 마을"을 실제 플레이 가능한 수준으로 만드는 것이다. 캐릭터 만들기(게스트 자동 가입) → 마을 입장 → 산책·충돌·깊이 → 채팅 → 별 모으기 → 점수·보상 조회 흐름을 로컬 서버와 연결한다. 두 계정 동기화와 20명 로컬 smoke를 유지한다.

이번 범위: 미니홈피 프레임 UI, 3개 장소 신규 맵, 공용 맵·충돌 모듈, 3계층 깊이 렌더링, 2등신 아바타, 키보드·방향패드·클릭/탭 이동, 장소 간 출입구 이동, 기존 채팅·별 모으기·결과·보상 계약.
추가 범위(PLAN-005·006): 첫 화면은 캐릭터 만들기(닉네임·피부·머리 색·머리 모양·옷 색)다. 입장하면 서버가 게스트 계정을 만들고 브라우저가 무작위 자격증명을 보관해 다음 방문에 자동 입장한다(원본의 UUID 방식 감각, 서버 검증 유지). 이메일 로그인 화면과 혼자 둘러보기(연습)는 없앴다. 게임 안 캐릭터 꾸미기로 언제든 수정한다.
추가 범위(PLAN-003): 상시 별 이벤트와 주기 정산, 별 상점(모자·옷·펫·가구), 옷장(입기·벗기), 펫 따라다니기, 개인 미니룸 가구 배치·저장, 최단 경로 클릭 이동, 큰 채팅창.
후속 범위: 다른 사람 미니룸 방문·방명록, 선물·현금 결제·환불, 친구·쪽지, 100명 운영, 실기기 키보드 보증, 운영 배포, 다른 기기에서 이어 하기(계정 연결), 채팅 신고.

## 4. 핵심 루프와 게임 경험

`캐릭터 만들기 → 광장 입장 → 산책(나무 뒤로 숨고 앞으로 나옴) → 채팅·인사 → 별 가까이 이동 → 서버 점수 → 3분 정산 → 지갑 → 상점에서 사기 → 입기·펫 → 미니룸에 가구 배치 → 다른 장소로 이동`.

### 4.1 맵 기획 (40×26 타일, 타일 16 도트, 월드 640×416)

세 장소는 바닥 재질, 구획, 동선, 소품, 목적이 모두 다르다. 출입구 매트를 밟으면 연결된 장소의 맞은편 입구로 이동한다. 우측 탭으로도 바로 이동할 수 있다.

**타운 광장 `lobby` — 만남의 장소.** 잔디 마을 한가운데 원형 석재 광장과 분수가 있다. 네 방향 모래길이 광장에서 뻗는다. 북쪽 길은 게시판 앞을 지나 두 건물(분홍 지붕 "미니홈피 하우스", 파란 지붕 "선물가게") 문 앞에 닿는다. 동쪽 길 끝 출입구는 정원, 서쪽 길 끝 출입구는 오락실로 이어진다. 남쪽 길에는 마을 입구 아치(foreground)가 걸려 있고 그 아래가 시작 지점이다. 광장 둘레에 벤치·가로등·화분이 있다. 가장자리에는 나무숲과 울타리를 둔다. 의도된 동선: 아치 아래 시작 → 분수 광장 → 게시판 → 건물 → 좌우 출입구.

**비밀 정원 `garden` — 산책과 대화.** 짙은 잔디와 디딤돌 길로 이루어진다. 서쪽 출입구(광장행)에서 덩굴 퍼걸러(foreground) 아래를 지나 연못으로 간다. 연못은 물 타일이라 들어갈 수 없다. 나무다리로만 건넌다. 다리 건너 북동쪽에 작은 온실이 있다. 남쪽에는 생울타리로 나눈 꽃밭 구획과 벤치 쉼터가 있다. 나무가 많아 나무 뒤로 숨는 깊이 표현이 가장 잘 드러나는 장소다. 의도된 동선: 입구 → 퍼걸러 → 연못 다리 → 온실 → 꽃밭 고리길 → 입구.

**스타 오락실 `arcade` — 별 모으기의 본거지.** 실내 맵이다. 위쪽은 네온 간판과 창문이 있는 벽이고 벽은 통과할 수 없다. 바닥은 보라·분홍 체크 타일이다. 북쪽 벽을 따라 오락기가 줄지어 있다. 가운데 등을 맞댄 오락기 섬이 있어 그 뒤로 지나가면 가려진다. 동쪽에는 인형뽑기 2대와 경품 카운터가 있다. 기둥 2개와 화분·소파가 있다. 남쪽 문 매트가 광장 서쪽 입구로 이어진다. 가운데 별 무대 러그가 미니게임 분위기를 만든다.

### 4.2 깊이와 충돌 규칙 (플레이어 체감 기준)

- 캐릭터·소품의 위치는 발밑(바닥 접점) 좌표다. 화면에서 발이 더 아래(남쪽)에 있는 것이 앞에 그려진다.
- 나무: 줄기 밑동만 막힌다. 캐릭터가 수관 아래(나무 북쪽)를 지나가면 수관에 가려진다. 나무 남쪽에 서면 나무 앞에 보인다.
- 건물: 벽의 바닥면만 막힌다. 지붕 그림 위쪽(건물 북쪽 뒤편 잔디)은 걸을 수 있고, 그곳에 서면 지붕에 가려진다.
- 아치·퍼걸러 상단은 항상 캐릭터 위에 그린다(foreground). 기둥만 막힌다.
- 물·벽·울타리·생울타리·꽃밭 타일은 통과할 수 없다. 길·광장·다리·바닥·러그·출입구 매트는 걸을 수 있다.
- 이동은 축별로 미끄러진다. 모서리에 걸리면 이동 방향으로 몇 도트 비켜 주어 끼임을 막는다.
- 시작·재입장·출입구 도착 지점은 항상 비어 있는 바닥이다.

### 4.3 별 모으기 규칙 (상시 이벤트, ADR-004)

- 시작 버튼이 없다. 방에 첫 사람이 들어오면 바로 진행되고 사람이 있는 동안 계속된다.
- 별은 방마다 최소 5개로 시작해 6초마다 1개씩 늘고 미회수 12개에서 멈춘다. 회수하면 다음 주기에 다시 채운다. 누락분을 몰아서 만들지 않는다.
- 새 별은 후보 24곳 중 기존 별·플레이어와 가장 먼 곳에 생겨 맵 전체로 흩어진다. 시작 지점에서 걸어서 갈 수 있고 수관·지붕에 가리지 않은 바닥에만 생긴다.
- 캐릭터 몸이 별 그림에 닿으면 먹는다(히트박스). 서버가 매 틱 자기 위치로 판정하고, 화면은 닿는 순간 별을 먼저 숨긴다. 별 1개 = 1점. 먼저 닿은 사용자만 얻는다. 먹는 즉시 "+1"이 뜨고 지갑 숫자가 오른다. 3분 정산 전 별은 "정산 대기"로 표시하고 상점에서는 정산 뒤에 쓸 수 있다.
- 3분마다 그 기간 점수를 정산해 결과·별 보상으로 저장하고, 맵의 별은 그대로 둔 채 다음 기간을 시작한다. 점수가 0인 사람은 기록을 남기지 않는다. 기간 합계가 64에 닿으면 바로 정산한다. 방이 비면 정산하고 멈춘다.
- 화면에는 내 점수, 맵의 별 수/12, 다음 정산까지 남은 시간, 기간 상위 3명을 보인다.

### 4.5 별 상점·옷장·미니룸 (ADR-004)

- 지갑 = 정산으로 받은 별 보상 합 − 산 물건 가격 합. 서버(PB 훅)가 계산하고 화면은 같은 원장으로 보여 준다.
- 상점 탭: 모자 4종, 옷 4종, 펫 4종, 가구 12종. 값은 4–30별. 같은 물건은 한 번만 산다. 별이 모자라면 살 수 없다.
- 옷장: 산 모자·옷·펫을 입거나 벗는다(슬롯마다 하나). 같은 방 사람들에게 바로 보인다. 펫은 주인 뒤를 따라 걷는다.
- 미니룸(우측 탭 🏠): 나만 들어가는 방. 산 가구를 바닥 격자에 놓고, 놓인 가구를 눌러 들어 올리고, 저장한다. 바닥 밖·문 앞·다른 가구와 겹침은 거절한다(러그는 다른 가구 밑에 깔 수 있음). 가구도 깊이 정렬·바닥 충돌을 따른다. 문 매트를 밟으면 광장으로 나간다.

### 4.4 실패 경험

캐릭터 저장 실패 이유 표시(이미 쓰는 닉네임은 입력칸 아래). 저장된 게스트 자격증명이 서버에서 거부되면 새 캐릭터 화면으로, 서버 연결 실패면 안내를 보여 준다. 연결 끊김 시 화면 전체를 막는 안내(자동 재접속 중 / 다시 연결 버튼), 이동·클릭·채팅·장소 이동 비활성. 방 이동 시 채팅·위치·말풍선을 새 방 것으로 교체. 같은 사용자의 같은 방 중복 접속 거절. 저장 지연 시 "기록 저장 중/재시도 중" 표시.

FR-004 추가: 채팅창은 데스크톱 최대 460×400(미니룸 높이 60%), 작은 화면 55% 높이로 여러 사람의 대화를 한 번에 본다.

| BR-017 | 미니룸 가구는 바닥 안·문 앞 제외·서로 겹치지 않게 놓는다(러그 제외). 같은 가구는 하나. 최대 24개. |

| BR-013 | 렌더링은 정수배 확대만 쓴다. 픽셀 보간(smoothing)을 끈다. 도트 소품·아바타에는 1도트 짙은 외곽선을 둔다. |
