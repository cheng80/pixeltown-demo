# AGENTS.md

> AI 작업용 진입점이다. 프로젝트 사실과 절차의 정본은 README, 명세, 현황, 작업 흐름에 있으며 여기에 복사하지 않는다.

## 읽기 순서
1. `docs/03_PROJECT_STATUS.md`의 현재 작업과 인수인계
2. 진행 중인 `plans/PLAN-xxx.md`가 있으면 해당 계획
3. 작업과 관련된 `01_PRODUCT_SPEC.md` / `02_TECH_SPEC.md`
4. 관련 코드와 테스트
5. 작업 절차가 필요할 때 `04_WORKFLOW.md`

## 갱신 위치
```text
제품 동작 / 핵심 UI → 01_PRODUCT_SPEC
구조 / 데이터 / API → 02_TECH_SPEC
현재 상태 / 다음 작업 / 인계 → 03_PROJECT_STATUS
작업 절차 → 04_WORKFLOW
중요한 결정의 이유 → ADR
```

## 작업 규칙
- 기존 구조와 패턴을 먼저 확인하고, 요청 밖 기능·의존성·대규모 리팩터링을 추가하지 않는다.
- 문서와 코드가 충돌하면 조용히 맞추지 말고 `DOC-CODE-MISMATCH` / `NEEDS-DECISION`으로 남긴다.
- 비밀정보/API 키를 코드나 문서에 기록하지 않는다.
- 문서의 규칙·예외·수치·명령을 임의로 요약하거나 이 파일에 중복하지 않는다.
- 완료 전 필요한 검증을 실행하고, 실행하지 않은 검증은 통과로 쓰지 않는다.
- 계약·상태·인계 정보가 바뀌면 같은 작업에서 해당 정본 문서를 갱신한다.
