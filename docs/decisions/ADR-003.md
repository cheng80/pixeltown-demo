# ADR-003 — 미니홈피 프레임 UI와 정수배 도트 스케일

- 상태: 채택 (재제작, 검증 결과는 PROJECT_STATUS)
- 날짜: 2026-10-02
- 관련: FR-004/007, BR-008/013, AC-006/011/016, PLAN-002

## 배경

이전 판은 반투명 파스텔 카드 4개를 맵 위에 띄웠다. 시스템 서체를 썼고 캔버스를 `devicePixelRatio`×비정수 zoom으로 그렸다. 도트가 번지거나 크기가 들쭉날쭉했다. 사용자는 싸이월드 도트 감성이 사라졌다고 거절했다.

## 결정

1. **프레임**: 데스크톱은 하늘색 점무늬 미니홈피 프레임 하나가 화면을 채운다. 짙은 자주 4px 외곽선과 아래쪽 단색 그림자를 둔다. 안에는 좌측 프로필 종이 패널, 가운데 미니룸 종이 패널(제목줄+캔버스+도구줄), 우측 폴더 탭을 둔다. 맵 위에 겹치는 것은 채팅·방향패드·토스트뿐이다.
2. **작은 화면**: 가로 900 또는 세로 520 미만이면 1열이다. 위 탭 줄, 미니룸, 아래 별 모으기 띠·도구줄 순서다. 프로필·수첩은 시트로 연다. `100dvh`와 visualViewport 높이로 맞추고 문서 스크롤을 막는다.
3. **글꼴**: OFL Galmuri11·Galmuri11-Bold를 npm `galmuri`에서 로컬 번들한다. CDN을 쓰지 않는다. 캔버스 이름표·말풍선도 같은 글꼴을 쓴다.
4. **도트 스케일**: 월드는 도트 해상도 오프스크린 캔버스에 그린다. 화면 캔버스에는 정수배(장치 픽셀 기준)로만 확대한다. `imageSmoothingEnabled=false`, CSS `image-rendering: pixelated`. 카메라 좌표는 정수 도트로 반올림한다. zoom은 미니룸 CSS 크기에 따라 2–4배 정수에서 고른다.
5. **외곽선**: 소품·아바타 스프라이트는 채움색으로 그린 뒤 알파 마스크 바깥 1도트에 짙은 자주 외곽선을 자동으로 두른다. 스프라이트는 종류·색·방향·프레임별로 캐시한다.
6. **팔레트**: 프레임 `#7cc4ec/#4f9fd0`, 선 `#3a2440`, 강조 `#ff5c93`, 종이 `#fffafc`, 점선 `#e3d4ff`, 별 `#ffd23f`. 맵은 장소별 고유 팔레트를 쓴다.

## 대안

- 비트맵 스프라이트 시트 제작: 원본 자산을 쓸 수 없고 외부 그래픽 도구가 필요하다. 절차 도트 + 자동 외곽선으로 대체했다.
- 캔버스 전체를 DPR 비정수 확대: 번짐 재발. 기각.

## 영향

- 캔버스가 프레임 패널 크기를 따르므로 보이는 월드 범위가 뷰포트마다 다르다. 카메라는 맵 경계에 고정한다. 맵이 화면보다 작으면 가운데 정렬한다.
- 폰트 약 670KB가 번들에 추가된다. 오프라인 실행을 유지한다.
